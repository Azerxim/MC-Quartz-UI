# Quartz UI

**White and clear GUI.**

Quartz UI is a minimalist resource pack that gives Minecraft's interface a clean, bright look made of white and rose quartz — without straying from the game's original layout or feel. If you love vanilla Minecraft but want a crisper, less muddy interface, this pack keeps everything familiar while giving it a polished finish.

![Main menu](https://raw.githubusercontent.com/Azerxim/MC-Quartz-UI/main/images/screenshots/main-menu.png)

## ✨ Features

- **White quartz panels**: translucent, rounded panels replace the grey and brown backgrounds, from inventories to menus, lists and tooltips.
- **Rose quartz engravings**: every container gets its own inlaid engraving — a hammer and saw on the crafting table, a flame on the furnace, a coiled still on the brewing stand, a horseshoe on the horse inventory, and many more.
- **Pill buttons with rose labels**: buttons become white quartz pills with a rose quartz gem, and their labels are written in a rose quartz gradient (English, Spanish and French).
- **Vanilla-faithful layout**: every slot, arrow and widget stays exactly where the game puts it — it's a re-skin, not a rework.
- **The whole interface**: all the 26.3 containers, the creative inventory and its tabs, the recipe book, the game mode switcher, advancements, books, the HUD (hearts in every state, armor, air, hotbar, boss bars) and the menus.
- **Mod Menu**: the "Mods" button of the title screen gets the same rose label.
- **Lightweight**: a pure 32x GUI pack, easy on performance and simple to combine with other packs.

## 🎨 Style

- **Resolution:** 32x
- **Theme:** Simplistic, vanilla-like
- **Palette:** Translucent white quartz with rose quartz accents, clean and bright

## 🕹️ How to use

1. Download the resource pack.
2. Drop it into your `.minecraft/resourcepacks` folder.
3. Enable it in **Options → Resource Packs**, above any conflicting packs if you're stacking it with others.
